# 박찬웅 포트폴리오

웹 접근성과 크로스브라우징을 지향하는 웹 퍼블리셔 박찬웅의 포트폴리오입니다.

## 🔗 링크

- **포트폴리오**: https://chan-wung.github.io/portfolio
- **GitHub**: https://github.com/chan-wung


## 🛠 기술 스택

- HTML5
- CSS3 / Tailwind CSS
- JavaScript (Vanilla)

## ✨ 주요 기능

- 스크롤 fade-up 애니메이션
- 타이핑 커서 효과
- 무한 마퀴 슬라이딩 (좌/우)
- 숫자 카운트업
- 이메일 클립보드 복사 + 토스트 알림
- 반응형 레이아웃 + 모바일 햄버거 메뉴
